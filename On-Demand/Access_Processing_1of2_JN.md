# RNA Sequence Data Processing 1of2 

During this hands-on activity, we will process an RNA sequencing (RNAseq) dataset hosted on OSDR using a Jupyter Notebook (JN) within a Google Colab environment.  
> _Notes:_
> - _We'll be using Google Colab, so if you haven't done so already, follow [these instructions](https://github.com/nasa/GeneLab-Training/blob/GL4U_Intro_2024_Colab/On-Demand/Colab_Instructions.md) to set up your Google account and verify access to Google Colab._
> - _This JN is part 1 of 2 parts that you will complete to process the RNAseq dataset. This JN is the hands-on activity associated with MODULE 2._
