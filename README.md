# GL4U Intro 

## Getting Started

The GL4U Intro notebooks are designed to run in [Google Colab](https://colab.research.google.com/) and use [Google Drive](https://drive.google.com/drive/home) for file storage. A [Google account](https://accounts.google.com/) is required.
To launch a notebook, click the "Open in Colab" button next to its name.
